# 屏幕适配方案

## 核心思路

**编辑器内统一使用 px 单位**，两种模式共享同一套 block 模板和样式管理器。
APP 模式仅在导出时做 `px → rem` 转换 + 注入 `flexible.js`，PC 模式仅在导出时做居中容器包裹。

无需在编辑器中做模式分支，降低维护成本。

---

## 编辑器内

### Block 模板

`blocks.js` 的 `px()` 辅助函数始终输出 `px`：

```js
const px = (v) => v + 'px'
```

所有 block 模板共用，`getBlocks()` 不再接收 `canvasMode` 参数。

### 样式管理器

所有尺寸属性统一用 `px` 单单位：

| 属性 | 单位 |
|------|------|
| `width` / `height` | `px` |
| `padding` / `margin` | `px` |
| `border-radius` | `px` |
| `font-size` | select：`12` `14` `16` `18` `20` `24` `32`（无单位后缀） |

- 单单位 → 不显示单位下拉框
- CSS 隐藏 `.gjs-field-unit { display: none }` → 用户只看到数字输入框

### 画布

- PC 模式：初始画布 desktop 宽度
- APP 模式：编辑器初始化时直接注册 `mobile-app` 设备（375px）并设为初始设备，避免运行时设备切换导致拖拽异常

### 拖拽钳制

`component:resize:end` 事件中限制元素宽度不超过画布可见宽度，防止拖出边界。

---

## 导出时

### PC 模式 HTML 导出

- 内容包裹 `<div class="page-container" style="max-width:1200px;margin:0 auto">`
- 保持原始 `px` 值不变
- viewport: `width=device-width`

### APP 模式 HTML 导出

1. `convertPxToRem(css)` 将 CSS 中尺寸属性的 `px` 值转换为 `rem`（÷16）
2. 转换后的 CSS 内联到 HTML
3. 注入 `flexible.js` + viewport meta（禁止用户缩放）

### JSON 导出（content_json）

- 存储 GrapesJS 原始项目数据，始终为 `px` 值
- 附带 `mode: 1 | 0` 标记，回显时根据 mode 切换画布设备
- JSON 不受导出转换影响

---

## 转换范围

`convertPxToRem()` 只转换以下 CSS 属性中的 `px` 值：

- `width` / `height` / `min-width` / `min-height` / `max-width` / `max-height`
- `padding` / `padding-top` / `padding-right` / `padding-bottom` / `padding-left`
- `margin` / `margin-top` / `margin-right` / `margin-bottom` / `margin-left`
- `font-size`
- `border-radius` / `border-top-left-radius` / `border-top-right-radius` / `border-bottom-left-radius` / `border-bottom-right-radius`
- `gap` / `row-gap` / `column-gap`
- `flex-basis`
- `top` / `right` / `bottom` / `left`

边框、阴影、字间距等不影响布局缩放的不转换。
